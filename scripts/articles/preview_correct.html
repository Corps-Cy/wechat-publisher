作为一名 OpenClaw 用户，你一定遇到过各种配置问题、连接失败或者莫名其妙的报错。别担心，这份手册汇集了 50 个最常见的故障场景，帮你快速定位问题并找到解决方案。

一、安装与启动问题（1-10）

1. OpenClaw 安装后无法启动

症状：运行 openclaw start 没有反应，或者提示"command not found"。

解决方案：

  1. 1.

    检查安装路径是否在 PATH 中：

    
1
echo PATH

    
2
which openclaw
  2. 2.

    如果找不到命令，添加到 PATH：

    
1
echo 'export PATH="HOME/.openclaw/bin:PATH"' >> ~/.bashrc

    
2
source ~/.bashrc
  3. 3.

    重新安装 OpenClaw：

    
1
curl -fsSL https://get.openclaw.ai | sh

2. 启动时提示"端口已被占用"

症状：Error: Port 3000 is already in use。

解决方案：

  1. 1.

    查找占用端口的进程：

    
1
lsof -i :3000
  2. 2.

    终止该进程：

    
1
kill -9
  3. 3.

    或更改 OpenClaw 端口：

    
1
openclaw config set port 3001

3. Docker 容器启动失败

症状：docker run 命令执行后容器立即退出。

解决方案：

  1. 1.

    查看容器日志：

    
1
docker logs
  2. 2.

    检查挂载目录权限：

    
1
ls -la ~/.openclaw

    
2
chmod -R 755 ~/.openclaw
  3. 3.

    确保 Docker 版本 >= 20.10：

    
1
docker --version

4. 权限错误：Permission denied

症状：无法访问某些文件或目录。

解决方案：

  1. 1.

    修复文件权限：

    
1
sudo chown -R (whoami):(whoami) ~/.openclaw

    
2
chmod -R 755 ~/.openclaw
  2. 2.

    如果使用 Docker，确保当前用户在 docker 组：

    
1
sudo usermod -aG docker USER

5. Node.js 版本不兼容

症状：提示"Node.js version too old"。

解决方案：

OpenClaw 需要 Node.js 18+ 或 20+。使用 nvm 安装：


1
nvm install 20


2
nvm use 20


3
node --version  # 确认版本 >= 20.0.0

6. 配置文件损坏

症状：启动时 JSON 解析错误。

解决方案：

  1. 1.

1
mv ~/.openclaw/config.json ~/.openclaw/config.json.backup

    
2
openclaw config init
  2. 2.

    手动修复 JSON 格式（如果需要保留配置）：

    
1

症状：npm ERR! network timeout 或包下载失败。

  2. 2.
