为什么选择 OpenClaw？

OpenClaw 是一个强大的 AI 助手框架，让你能在本地快速部署智能助手。相比云端方案，它具有完全数据隐私、高度可定制、零使用费用的优势。

根据 GitHub 数据，已有超过 2000+ 开发者在本地部署了 OpenClaw，平均部署时间仅需 15 分钟。

前置要求

硬件要求

最低配置：

  • CPU: 2 核
  • 内存: 4GB
  • 硬盘: 10GB

推荐配置：

  • CPU: 4 核以上
  • 内存: 8GB 以上
  • 硬盘: 20GB 以上

软件要求

必须安装：

  • Node.js: v18.0.0 或更高版本（推荐 v20+）
  • npm: v9.0.0 或更高版本
  • Git: 最新稳定版

可选组件：

  • Docker: 用于容器化部署
  • PM2: 用于进程管理（生产环境推荐）

安装方式选择

OpenClaw 提供三种安装方式：

方式 适用场景 难度 时间
NPM 全局安装 快速体验、开发环境 ⭐ 5分钟
源码编译 深度定制、开发贡献 ⭐⭐⭐ 15分钟
Docker 部署 生产环境、团队协作 ⭐⭐ 10分钟

方式一：NPM 全局安装（推荐新手）

步骤 1：安装 OpenClaw CLI
